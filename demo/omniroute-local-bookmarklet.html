Local same-origin diagnostic

OmniRoute Local Tester

This bookmarklet must run from the local OmniRoute dashboard. It first probes the local health endpoint, then sends a real OpenAI-compatible chat request. It displays the page origin and target URLs so a browser/network failure can be diagnosed accurately.

Install once

  1. Click Copy bookmarklet.
  2. Create a browser bookmark, edit it, and paste the copied value as its URL. Name it Test OmniRoute Local.
  3. On the same device, open http://localhost:20128/dashboard/endpoint.
  4. Only from that local dashboard tab, open the saved Test OmniRoute Local bookmark.
Test OmniRoute Local
Desktop: drag the green bookmark link to the bookmarks bar. Mobile: copy the bookmarklet, then paste it into a bookmark’s URL field. Do not tap the green link on this HTTPS helper page.
Expected first result: Same-origin health probe returned HTTP 200 (or another HTTP status). If it instead says LOCAL NETWORK PROBE FAILED, copy the diagnostic panel text but never share your API key.
