OmniRoute Local Tester

This is the browser-safe alternative to the hosted demo. The generated bookmarklet runs inside your local OmniRoute dashboard, so its request is http://localhost:20128 → http://localhost:20128. No HTTPS-to-HTTP mixed-content request occurs.

Install once

  1. Click Copy bookmarklet.
  2. Create any browser bookmark, edit it, and replace its URL with the copied text. Name it Test OmniRoute Local.
  3. Open your local OmniRoute Endpoints dashboard on the same device.
  4. Open the Test OmniRoute Local bookmark. Enter a newly generated OmniRoute API key, model auto, and your prompt.
Why this works: it calls the relative path /v1/chat/completions from the local OmniRoute dashboard itself. Do not run this bookmark from the HTTPS GitHub preview page—run it only after you have navigated to http://localhost:20128/dashboard/endpoint.

What the tester does

It uses Authorization: Bearer <your API key>, sends an OpenAI-compatible non-streaming chat request, and displays the HTTP status plus raw JSON in a closable overlay. It does not persist the key, write settings, or put the key in a URL.
