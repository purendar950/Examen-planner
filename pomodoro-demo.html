Toggle Pomodoro on a running task → the popup shows the 25-min focus countdown + block number. At 0 it auto-flows to a 5-min break (clock pauses, so breaks never count as study time), then back to focus. Long break after 4 blocks. Chime + notification at each switch (🔔 mute button).
